# Bank App

Консольное банковское приложение на Java: клиенты, текущие и накопительные счета, пополнение, снятие, переводы, выписка и начисление процентов. Данные сохраняются в файл между запусками. Внешние библиотеки не нужны, достаточно JDK.

> A console banking application in Java 17+ demonstrating OOP (inheritance, polymorphism, encapsulation), custom exceptions, `BigDecimal` for money and file persistence.

## Возможности

- Регистрация клиентов и открытие счетов двух типов:
  - **текущий** с настраиваемым овердрафтом (разрешённый уход в минус);
  - **накопительный** с процентной ставкой, в минус уходить нельзя.
- Пополнение, снятие и переводы между счетами
- Выписка по счёту: дата, тип операции, сумма и баланс после операции
- Ежемесячное начисление процентов по накопительным счетам
- Понятные сообщения об ошибках (недостаточно средств, неверная сумма, счёт не найден)
- Автоматическое сохранение в `data/bank.dat`

## Запуск

Нужен JDK 17 или новее (проверка: `javac -version`).

**Через терминал** (из папки проекта):

```bash
# Linux / macOS
javac -d out $(find src -name "*.java")
java -cp out bank.Main
```

```powershell
# Windows (PowerShell)
javac -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out bank.Main
```

**Через VS Code:** установите расширение *Extension Pack for Java*, откройте папку проекта (`File → Open Folder`), откройте `src/bank/Main.java` и нажмите **Run** над методом `main`.

> Если на Windows русские буквы в консоли отображаются неправильно, выполните `chcp 65001` перед запуском.

## Пример работы

Клиент открывает текущий счёт с овердрафтом 50 000 тг, пополняет его на 120 000 тг и переводит 80 000 тг на накопительный счёт под 8% годовых. После этого он пробует снять 500 000 тг, а банк начисляет проценты:

```
Счёт открыт: Текущий KZ00000001 (Бекзат Құдайберген): 0.00 тг
Счёт открыт: Накопительный KZ00000002 (Алия Нурланова): 0.00 тг
Готово. Текущий KZ00000001 (Бекзат Құдайберген): 120000.00 тг
Перевод выполнен
Текущий KZ00000001 (Бекзат Құдайберген): 40000.00 тг
Накопительный KZ00000002 (Алия Нурланова): 80000.00 тг
Ошибка: Недостаточно средств на счёте KZ00000001: доступно 90000.00, требуется 500000.00
Начислено процентов всего: 533.33 тг

Накопительный KZ00000002 (Алия Нурланова): 80533.33 тг
№   Дата             Операция                      Сумма       Баланс
1   05.10.2026 08:39 Перевод (входящий)         80000.00     80000.00
2   05.10.2026 08:39 Начисление процентов         533.33     80533.33
```

Доступно 90 000 тг, потому что на счёте 40 000 тг плюс овердрафт 50 000 тг. Проценты: 80 000 × 8% ÷ 12 = 533.33.

## Структура проекта

```
src/bank/
  Account.java                  абстрактный счёт: баланс, история, пополнение и списание
  CurrentAccount.java           текущий счёт с овердрафтом
  SavingsAccount.java           накопительный счёт с процентами
  Bank.java                     клиенты, счета, переводы, сохранение в файл
  Customer.java, Transaction.java, TransactionType.java
  BankException.java и его наследники (InvalidAmount, InsufficientFunds, AccountNotFound)
  Main.java                     консольное меню
  test/BankTests.java           15 тестов
```

## Технические решения

- **Наследование и полиморфизм.** `CurrentAccount` и `SavingsAccount` наследуют `Account` и по-своему реализуют `getAvailableFunds()`. Код снятия средств один и тот же, а правила зависят от типа счёта.
- **Инкапсуляция.** Баланс нельзя изменить напрямую. Все изменения идут через методы счёта, поэтому каждая операция попадает в историю. Методы `credit` и `debit` видны только внутри пакета, их использует банк для переводов.
- **`BigDecimal` вместо `double`** для денег, чтобы не было ошибок округления. Сумма проверяется: больше нуля и не более двух знаков после запятой.
- **Собственные исключения** с понятными сообщениями. Если перевод не удался, деньги не списываются и не зачисляются.
- **Неизменяемые данные.** `Transaction` и `Customer` это `record`, а историю операций наружу отдаёт только для чтения.
- **Сохранение** через стандартную сериализацию Java.

## Тесты

Тесты написаны без внешних библиотек (простой собственный запуск), чтобы проект собирался одним `javac`.

```bash
java -cp out bank.test.BankTests
```

В конце выводится `Пройдено: 15, упало: 0`. Проверяются пополнение и снятие, овердрафт, запрет ухода в минус на накопительном счёте, неверные суммы, переводы (включая неудачный), проценты, точность денег и сохранение в файл.

## Ограничения и планы

- Нет авторизации и паролей, это учебный проект.
- Сериализация привязана к версии классов: если менять структуру классов, старый `data/bank.dat` придётся удалить. Лучше хранить данные в базе данных (JDBC и SQLite или PostgreSQL).
- Переход на Maven и тесты на JUnit 5.
- REST API на Spring Boot поверх этой логики.
